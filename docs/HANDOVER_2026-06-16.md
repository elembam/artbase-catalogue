## What ArtBase / Ars Accordia is

**ArtBase** is a standards-compliant cataloguing service for Latvian art collections (private, corporate, institutional). The public face is **arsaccordia.com**.

The core deliverable is an **Artwork Passport**: a per-artwork document linking identity, provenance, authority records, and export-ready data. Each artist gets a profile page at `arsaccordia.com/artists/{ART-ID}.html`.

**Tech stack:** Airtable (source) → Python export scripts → canonical JSON in Git → Jinja2 HTML generation. No database server. Static files on Cloudflare Pages / Netlify.

**Repository:** `/Users/elemba/VSCode/ArtBank/ArtBase/` (also on GitHub as `elembam/artbase-catalogue`)

## Collections structure

### Option A is implemented
Artist profiles are the hub. Each `artists/ART-*.html` page has a **Collection Appearances** section linking back to collection pages. The `collections` array in each artist JSON drives this.

```
arsaccordia.com/collections/lnmm/      → LNMM collection page (live)
arsaccordia.com/collections/hansabanka/ → Hansabanka (placeholder, not yet built)
arsaccordia.com/artists/ART-ID.html   → artist profiles (hub)
```

The template is `templates/artist_profile.html.j2` (already has Collection Appearances section with CSS).

**Configuration fix applied:** Removed the `P973` Wikidata property field (was causing errors — P973 is a URL property, not an external ID property). Catalog now only stores the match in the Mix'n'match database.

**SPARQL automatch query** (to add in catalog editor if not already set):
```sparql
SELECT ?item ?id WHERE {
  ?item wdt:P973 ?url .
  BIND(REPLACE(STR(?url), "https://arsaccordia.com/artists/(.+)\\.html", "$1") AS ?id)
  FILTER(STRSTARTS(STR(?url), "https://arsaccordia.com/artists/"))
}
```

## Notes on QuickStatements format

Current correct format for P973 batches (no S248 until Ars Accordia has a Q-item):
```
Q[ARTIST_QID]	P973	"https://arsaccordia.com/artists/ART-ID.html"	S854	"https://arsaccordia.com/artists/ART-ID.html"	S813	+2026-06-16T00:00:00Z/11
```

Tab-separated. Paste at https://quickstatements.toolforge.org/ → "Import V1 commands".

**Known issue:** "ADD Sources error" may appear even when references attach correctly. Check the Wikidata item directly after submission to confirm.

**DO NOT use S248 Q54919** (that's VIAF, not Ars Accordia). S248 for Ars Accordia can only be added once the Ars Accordia Wikidata item exists and has been approved.
