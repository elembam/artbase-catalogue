# Wikidata Contributions

This directory contains all QuickStatements batches for contributing ArtBase data to Wikidata.

## Start here

**[CONTRIBUTIONS_LOG.md](CONTRIBUTIONS_LOG.md)** — master tracker: what's been submitted, what's ready,
what's planned, and why each contribution matters to the Ars Accordia site.

## File naming

- `<name>_YYYYMMDD.qs` — QuickStatements V1 batch (ready to paste)
- `<name>_YYYYMMDD.review.md` — Pre/post submission checklist for that batch
- `<name>_draft.qs` — Work in progress, not yet ready to submit

## Rules

All batches are PROPOSALS only. None are auto-submitted. Submission requires:
1. Read the `.review.md` file fully
2. Log into https://quickstatements.toolforge.org/ as **Arsaccordia**
3. Paste and run manually
4. Update CONTRIBUTIONS_LOG.md with batch ID and result

Every batch is committed to git. Git history = permanent audit trail.

See `docs/quickstatements_runbook.md` for the full submission procedure.
